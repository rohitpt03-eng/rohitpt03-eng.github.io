# Rohit — Portfolio

**B.Tech ECE Student | Programmer | Web Developer**

Welcome to my personal portfolio landing page built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features
- **Modern Dark Theme**: Designed with `#0C0C0C` background and Google Font `Kanit`.
- **Interactive Magnetic Hero**: Mouse-following portrait effect with Framer Motion.
- **Scroll Marquee**: Dynamic dual-row animated preview tiles responding to scroll position.
- **Character Reveal Animation**: Fluid scroll-driven opacity reveal for the About section.
- **What I Do & Skills**: Showcasing C/C++ programming, web development, digital electronics, and embedded systems.
- **Sticky Stacking Projects**: Interactive project cards that stack and scale down as you scroll.

## 🛠️ Tech Stack
- React 18 & TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vite

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
